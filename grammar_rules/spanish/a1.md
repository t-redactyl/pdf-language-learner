## Regular -ar verbs

Verbs in Spanish end with either -ar, -er or -ir. Regular verbs ending in -ar in the present tense (_el presente_) have the following conjugations.

| Pronoun | Ending | Example (estudiar) |
| ------- | ------ | ------------------ |
| yo | -o | estudio |
| tú | -as | estudias |
| él/ella/usteds | -a | estudia |
| nosotros/nosotras | -amos | estudiamos |
| vosotros/vosotras | -aís | estudiaís |
| ellos/ellas/ustedes | -an | estudian |

## Indefinite articles

Indefinite articles in Spanish depend on the gender and number of nouns.

| Gender | Masculine | Feminine |
| ------ | --------- | -------- |
| Singular | **un** diccionario | **una** guitarra |
| Plural | **unos** diccionarios | **unas** guitarras |

<!-- topic: es_a1_u2_masculine_feminine_professions -->
## Masculine and feminine professions

Professions in Spanish change gender largely based on their word ending, although there is also a group of professions where the masculine and feminine forms are the same.

| -o > -a | -or > -ora | masculine = feminine |
| ------- | ---------- | -------------------- |
| el enfermero - la enfermera | el profesor - la profesora | el dentista - la dentista |
| el empleado - la empleado | el programador - la programadora | el policia - la policia |
| el camarero - la camarera | el director - la directora | el representante - la representante |

<!-- topic: es_a1_u2_negation -->
## Negation

Verbs are negated in Spanish by adding "no" before the verb:
* ¿Hablas francés? **No, no** hablo francés.
* Verónica **no** es profesora.
* Margarita **no** tiene móvil.

## Regular -er and -ir verbs

Verbs in Spanish end with either -ar, -er or -ir. 

Regular verbs ending in -er in the present tense (_el presente_) have the following conjugations.

| Pronoun | Ending | Example (aprender) |
| ------- | ------ | ------------------ |
| yo | -o | aprendo |
| tú | -es | aprendes |
| él/ella/usteds | -e | aprende |
| nosotros/nosotras | -emos | aprendemos |
| vosotros/vosotras | -eís | aprendeís |
| ellos/ellas/ustedes | -en | aprenden |

Regular verbs ending in -ir in the present tense have the following conjugations.

| Pronoun | Ending | Example (vivir) |
| ------- | ------ | ------------------ |
| yo | -o | vivo |
| tú | -es | vives |
| él/ella/usteds | -e | vive |
| nosotros/nosotras | -imos | vivimos |
| vosotros/vosotras | -ís | vivís |
| ellos/ellas/ustedes | -en | viven |

## Verbs tener and ser

The verbs "tener" (to have) and "ser" (to be) have an irregular conjugation.

| Pronoun | tener | ser |
| ------- | ----- | --- |
| yo | tengo | soy |
| tú | tienes | eres |
| él/ella/usteds | tiene | es |
| nosotros/nosotras | tenemos | somos |
| vosotros/vosotras | tenéis | sois |
| ellos/ellas/ustedes | tienen | son |

<!-- topic: es_a1_u3_adjectives -->
## Adjectives

In Spanish, adjectives decline based on the gender and number of objects. Certain adjectives do not change their form based on the gender of the noun, but all adjectives change based on whether the noun is singular or plural.

| Number | Masculine | Feminine |
| ------ | --------- | -------- |
| Singular | un hombre atractiv**o** | una mujer atractiv**a** |
|  | un trabajo interesant**e** | una persona interesant**e** |
| | un hobby original | una idea original |
| Plural | hombres atractiv**os** | mujeres atractiv**as** |
|  | trabajos interestant**es** | personas interesant**es** |
|  | hobbies original**es** | ideas original**es** |

<!-- topic: es_a1_u3_questions -->
## Questions

The words "quién", "quiénes", "cuántos", "cuántas" and "por qué" can change depending on the quantity and gender of the noun.

| Spanish | English | Rule |
| ------- | ------- | ---- |
| **¿Quién** es ... ? | Who is ... ? | A single person |
| **¿Quiénes** son ... ? | Who are ... ? | Multiple people |
| **¿Cuántos** empleados ... ? | How many ... ? | Masculine nouns |
| **¿Cuántas** chocolaterías ... ? | How many ... ? | Feminine nouns |
| **¿Por qué?** | Why? | |

<!-- topic: es_a1_u5_direct_object_pronouns -->
## Direct object pronouns

Direct object pronouns (_complemento directo_) replace a noun that receives the action of the verb directly, without any preposition attached. They answer the question "¿qué?" (what?) or "¿a quién?" (whom?).

| Person | Pronoun | Example sentence with noun | Replaced with pronoun |
| ------ | ------- | --------------------------- | ---------------------- |
| 1st singular | me | Mi amigo **me** ve. | **Me** ve. |
| 2nd singular (informal) | te | Yo **te** veo. | **Te** veo. |
| 3rd singular masculine | lo | Compro **el libro**. | **Lo** compro. |
| 3rd singular feminine | la | Compro **la revista**. | **La** compro. |
| 3rd singular (formal "usted") | lo / la | Conozco **a usted**. | **Lo/La** conozco. |
| 1st plural | nos | Ella **nos** llama. | **Nos** llama. |
| 2nd plural (informal, Spain) | os | Yo **os** quiero. | **Os** quiero. |
| 3rd plural masculine / formal plural | los | Veo **a los niños**. | **Los** veo. |
| 3rd plural feminine | las | Veo **las fotos**. | **Las** veo. |

### Placement

| Verb form | Position of pronoun | Example |
| --------- | -------------------- | ------- |
| Conjugated verb | Before the verb | **Lo** tengo. |
| Infinitive | Before the conjugated verb, or attached to the end of the infinitive | **Lo** voy a comprar. / Voy a comprar**lo**. |
| Gerund | Before the conjugated verb, or attached to the end of the gerund (with a written accent) | **Lo** está leyendo. / Está leyéndo**lo**. |
| Affirmative command | Attached to the end | ¡Cómpra**lo**! |
| Negative command | Before the verb | ¡No **lo** compres! |


### Complemento directo vs. indirecto vs. reflexivo: cómo distinguirlos

Spanish has three pronoun sets that are easy to confuse, since the 1st and 2nd person forms (me, te, nos, os) are shared across all three. The tests below establish which one is at play.

| Test | Question to ask | Direct object | Indirect object | Reflexive |
| ---- | ---------------- | -------------- | ----------------- | ----------- |
| Question test | What does the pronoun answer? | ¿qué? / ¿a quién? (what/whom, no preposition) | ¿a quién? / ¿para quién? (to/for whom, implicit "a") | Same question as direct/indirect, but the answer is the subject itself |
| Self-test | Can you naturally insert "-self/-selves"? | No | No | Yes |
| Identity test | Is the object a different entity from the subject? | Usually yes | Usually yes | No — subject and object are the same person |
| Verb-type test | Does the verb inherently involve transferring something to a person? | No | Often (dar, decir, escribir, mostrar) | Irrelevant — depends on subject/object identity, not verb category |

### Worked examples

| Sentence | Pronoun | Category | Why |
| -------- | ------- | -------- | --- |
| Veo la película. → **La** veo. | la | Direct | "la" = the movie itself, directly seen |
| Doy el libro a mi hermana. → **Le** doy el libro. | le | Indirect | "le" = to whom the book goes; el libro stays the direct object |
| Me lavo. | me | Reflexive | Subject (yo) and object (myself) are identical |
| Me lavo las manos. | me | Reflexive | Same subject/object identity; "las manos" is a separate direct object |
| Se mira en el espejo. | se | Reflexive | Passes the self-test: "he looks at *himself*" |
| Lo mira. | lo | Direct | Fails the self-test: "he looks at *it/him* [something else]" |

### Special case: gustar-type verbs

Verbs like *gustar*, *encantar*, *doler* and *faltar* always take an **indirect** object pronoun, even where German or English grammar would suggest a direct construction — the noun that follows is grammatically the subject, not the object:

| Spanish | Literal structure | English equivalent |
| ------- | ------------------ | -------------------- |
| **Me** gusta el café. | Coffee is pleasing **to me**. | I like coffee. |
| **Le** duele la cabeza. | The head hurts **to him/her**. | His/her head hurts. |

## Numbers above 100

Numbers in Spanish are formed by saying each component one by one until the single digit, which is added with and ("y"). This includes when saying years.

Below is the pattern for all numbers below 100.

| 0 - 9 | 10 - 19 | 20 - 29 | 30 - 39 (same pattern holds for all "decenas") |
| ----- | ------- | ------- | ---------------------------------------------- |
| **0** cero | **10** diez | **20** veinte | **30** treinta |
| **1** uno (un/una) | **11** once | **21** veintiuno | **31** treinta y uno (un/una) |
| **2** dos | **12** doce | **22** veintidós | **32** treinta y dos |
| **3** tres | **13** trece | **23** veintitrés | **33** treinta y tres |
| **4** cuatro | **14** catorce | **24** veinticuatro | **34** treinta y cuatro |
| **5** cinco | **15** quince | **25** veinticinco | **35** treinta y cinco |
| **6** seis | **16** dieciséis | **26** veintiséis | **36** treinta y seis |
| **7** siete | **17** diecisiete | **27** veintisiete | **37** treinta y siete |
| **8** ocho | **18** dieciocho | **28** veintiocho | **38** treinta y ocho |
| **9** nueve | **19** diecinueve | **29** veintinueve | **39** treinta y nueve |

Here are the remaining building blocks both above and below 100.

| Las decenas | Las centenas | Otros numeros |
| ----------- | ------------ | ------------- |
| **10** diez | **100** cien(to) | **1,000** mil |
| **20** veinte | **200** doscientos/as | **10,000** diez mil |
| **30** treinta | **300** trescientos/as | **100,000** cien mil |
| **40** cuarenta | **400** cuatrocientros/as | **1,000,000** un millón |
| **50** cincuenta | **500** quinientos/as | **10,000,000** diez millones |
| **60** sesenta | **600** seiscientos/as | **100,000,000** cien millones |
| **70** setenta | **700** setecientos/as | **1,000,000,000** mil millones |
| **80** ochenta | **800** ochocientos/as | **100,000,000,000** cien mil millones |
| **90** noventa | **900** novecientos/as | **1,000,000,000,000** un billón |

## Irregular verbs (querer, preferir, poder, probar)

"Querer" (to want), "preferir" (to prefer), "poder" (to be able to) and "probar" (to try) are another set of important verbs with irregular conjugation.

| Pronoun | querer (e > ie) | preferir (e > ie) | poder (o > ue) | probar (o > ue) |
| ------- | --------------- | ----------------- | -------------- | --------------- |
| yo | quiero | prefiero | puedo | pruebo |
| tú | quieres | prefieres | puedes | pruebas |
| él / ella / usted | quiere | prefiere | puede | prueba |
| nosotros / nosotras | queremos | preferimos | podemos | probamos |
| vosotros / vosotras | queréis | preferís | podéis | probáis |
| ellos / ellas / ustedes | quieren | prefieren | pueden | prueban |

<!-- topic: es_a1_u5_telling_time -->
## Telling time

Time in Spanish is told with the form _ser + la/las + hour + minutes_. The exact minutes are usually used. When the time is after half past the hour, how many minutes to the next hour can be used, but this is archaic.

| time | ser | la/las | hour | minutes |
| ---- | --- | ------ | ---- | ------- |
| 13:00 | es | la | una | (en punto) |
| 14:00 | son | las | dos | (en punto) |
| 14:15 | son | las | dos | y cuarto / quince |
| 14:25 | son | las | dos | y venticinco |
| 14:30 | son | las | dos | y media |
| 14:35 | son | las | dos | y treinta y cinco |
| 14:45 | son | las | dos | y cuarenta y cinco |
| 14:50 | son | las | dos | y cincuenta |

Here is how you would say some of these times in the old-fashioned style.

| time | ser | la/las | hour | minutes |
| ---- | --- | ------ | ---- | ------- |
| 14:35 | son | las | tres | menos veinticinco |
| 14:45 | son | las | tres | menos cuarto |
| 14:50 | son | las | tres | menos diez |
